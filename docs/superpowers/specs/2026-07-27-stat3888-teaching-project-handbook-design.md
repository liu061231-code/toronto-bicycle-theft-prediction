# STAT3888 教学型项目手册 PDF 设计说明

## 1. 目标

制作一份中文为主、英文术语对照的教学型 PDF，使尚未学到基函数回归的学生能够：

1. 从已掌握的高等代数和概率论进入时空数据建模；
2. 理解为什么选择 `bicycle.csv` 和 Task 4；
3. 理解时空基函数回归的原理、假设、优势与局限；
4. 独立完成数据清洗、探索、建模、验证、解释与展示；
5. 将本项目积累的方法迁移到 GAM、正则化回归和后续机器学习课程。

PDF 不是项目答案代写，也不是只给代码的操作说明。它必须同时提供理论桥梁、完整流程、可运行代码、检查标准和展示策略。

## 2. 项目方案

### 2.1 数据与任务

- 数据：`bicycle.csv`
- 必做任务：Task 1 时空可视化
- 选修任务：Task 4 Linear Regression with Basis Functions
- 研究单位：社区 × 月份
- 响应变量：每个社区每月自行车盗窃次数
- 主研究问题：时空基函数能否预测社区层面的自行车盗窃数量，并解释盗窃活动随空间、季节和长期时间的变化？

### 2.2 主模型

主模型为正则化时空基函数回归：

\[
\log(1+y_{s,t}) =
\beta_0 +
B_{\mathrm{trend}}(t)\beta_t +
B_{\mathrm{season}}(t)\beta_s +
B_{\mathrm{space}}(lon_s,lat_s)\beta_g +
\varepsilon_{s,t}.
\]

其中：

- 长期趋势使用 B-spline 或自然样条；
- 年度季节性使用 Fourier 正弦/余弦基函数；
- 空间变化使用径向基函数或薄板样条；
- 多个基函数系数使用 Ridge 正则化控制复杂度；
- 普通线性模型作为题目合规基线，正则化模型作为现代化主模型。

### 2.3 验证设计

- 训练集：2014–2021；
- 验证集：2022；
- 最终测试集：2023；
- 使用滚动时间验证说明未来预测能力；
- 使用留出社区或空间分块作为空间泛化敏感性检查；
- 禁止随机拆分全部行，避免相邻月份和相同社区信息泄漏；
- 与全局均值、社区历史均值和简单季节模型比较；
- 评价指标包括 MAE、RMSE、测试集 \(R^2\) 与残差地图。

## 3. 教学设计原则

### 3.1 三层学习路线

每一章标记为：

- 核心路线：完成项目必须掌握；
- 进阶加分：提高方法深度与评分；
- 未来连接：本项目后续可迁移的方向，不要求当前完全掌握。

### 3.2 每个方法的固定解释模板

每个概念依次回答：

1. 它解决什么问题；
2. 输入和输出是什么；
3. 与已学知识怎样连接；
4. 公式中每个符号是什么；
5. 矩阵或向量维度是什么；
6. 为什么适合本数据；
7. 有什么优势和假设；
8. 什么情况下不能使用；
9. R 代码怎样对应公式；
10. 如何检查结果是否可信。

### 3.3 代码教学标准

- 核心代码可以从头到尾按顺序运行；
- 每段代码先写目的，再写代码，再解释关键对象；
- 不使用未说明来源的对象；
- 所有随机过程设置种子；
- 文件路径集中设置，不散落硬编码；
- 保存中间清洗数据、图表、模型和指标；
- 对常见错误给出症状、原因和修复方法；
- 核心实现依赖尽量少，进阶包明确标为可选。

## 5. 软件与工具

核心软件：

- R；
- RStudio；
- WPS Office，用于查看最终 PDF 和制作/检查 PowerPoint。

核心 R 包：

- `tidyverse`：数据整理与可视化；
- `lubridate`：日期与月份；
- `splines`：B-spline/自然样条；
- `glmnet`：Ridge 正则化；
- `yardstick` 或基础 R：评价指标。

进阶可选：

- `sf`：空间数据结构；
- `mgcv`：惩罚样条和 GAM 对照；
- `rsample`：时间滑动验证；
- `spatialsample`：空间分块验证；
- `patchwork`：组合图表。

- 社区平均盗窃量空间气泡图；
- 社区 × 月份时空热力图；
- 三类基函数示意图；
- 训练/验证/测试时间切分图；
- 基线与主模型指标对比；
- 2023 观测值与预测值地图；
- 残差空间分布图；
- 项目完整工作流图；
- 从本项目通向后续模型的学习路线图。

图表必须使用色觉友好配色、固定颜色尺度、完整标题、单位、图例、时间范围和数据来源说明。

## 7. 最终 PPT 逻辑

最多四页：

1. 研究问题、数据和工作流；
2. 时空探索结果；
3. 时空基函数模型与验证结果；
4. 预测、残差、结论和局限性。

PDF 需要明确说明每页保留什么、删掉什么，以及每张图回答哪个问题。

## 8. 质量保证

### 内容检查

- 与原始项目 PDF 的任务和评分标准一致；
- 不把 GAM、随机森林或深度学习伪装成老师要求的方法；
- 不把相关关系写成因果关系；
- 不把社区盗窃次数写成个人盗窃风险；
- 明确社区中心坐标、暴露量缺失和重复记录的不确定性；
- 所有方法选择都有数据与评分依据。

### 代码检查

- 在真实 `bicycle.csv` 上从头运行；
- 检查对象名、列名、日期和季度；
- 检查训练、验证和测试集时间边界；
- 检查测试信息没有进入训练阶段；
- 检查预测反变换和评价指标；
- 输出图表与文字结论一致。

### PDF 检查

- 使用 ReportLab 生成；
- 使用支持中文的本机字体；
- 公式、表格和代码不越界；
- 页码、章节标题、页眉页脚一致；
- 逐页渲染为 PNG 并视觉检查；
- 用 PDF 文本提取检查章节和中文；
- 最终使用 WPS Office 打开预览。

## 10. 范围边界

- 当前阶段制作教学手册和可复现项目路线，不代替用户理解结果；
- 主线保持在 Task 1 + Task 4；
- EOF、IDW、GAM、树模型和神经网络只作比较或未来连接；
- 不虚构尚未实际运行得到的模型分数和结论；
- 最终结果必须以真实数据运行输出为准。
