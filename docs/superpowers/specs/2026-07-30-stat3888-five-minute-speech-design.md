# STAT3888 五分钟演讲稿与原理解析设计

## 目标

依据最终四页演示文稿、项目要求和真实 R 输出，制作一份适合五分钟正式汇报的中文演讲稿，以及一份与演讲稿分离的学习型原理解析。正式演讲严格覆盖 Task 1（时空可视化）与 Task 4（基函数线性回归），不扩展为额外研究项目。

## 受众与知识基础

- 演讲受众：STAT3888 任课教师和同学。
- 使用者基础：已经学习高等代数和概率论，不默认掌握时间序列、空间统计、GIS、回归正则化或基函数。
- 表达原则：先解释问题和直觉，再给公式；每个公式都说明符号、用途和与 PPT 图表的关系。

## 输出

1. 可编辑 Word 文档。
2. 同内容 PDF 文档。
3. 文档包含两个清晰分区：
   - 第一部分：五分钟逐页演讲稿。
   - 第二部分：方法原理、公式解释和答辩速查。

## 五分钟演讲结构

### 0:00–0:30 数据与研究问题

- 介绍 Toronto bicycle theft 数据、140 个 neighbourhood、2014–2023 年。
- 明确问题：盗窃在时间和空间上如何变化，以及能否预测 neighbourhood-month 的盗窃次数。

### 0:30–1:45 Task 1：时空可视化

- 第 1 页：长期趋势与季节循环。
- 第 2 页：空间热点、时空热力图和动画。
- 解释每张图回答的具体问题，而不是只描述颜色或曲线。

### 1:45–3:45 Task 4：基函数线性回归

- 将 neighbourhood-month 计数作为响应变量。
- 用 `log(1+y)` 缓解计数分布偏斜。
- 用 B-spline 表示平滑长期变化。
- 用 sine/cosine 表示年度季节循环。
- 用 RBF 表示空间邻近关系。
- 先说明 Basis OLS 是 Task 4 的标准模型，再说明 Basis Ridge 是稳定化扩展。
- 解释按时间顺序划分训练集、验证集和测试集，避免用未来信息预测过去。

### 3:45–4:40 模型结果与诊断

- Global mean、Neighbourhood mean、Basis OLS、Basis Ridge 进行同一 2023 测试集比较。
- 报告真实结果：Basis OLS RMSE 2.05、R² 0.757；Basis Ridge RMSE 2.06、R² 0.754。
- 说明 Ridge 虽然 RMSE 比 OLS 高 0.01，但在相关基函数下系数更稳定，因此作为主要解释模型。
- 简要指出高峰月份仍容易低估，体现模型局限。

### 4:40–5:00 结论

- 总结夏季高峰、downtown 热点、基函数模型显著优于简单基线。
- 强调结论适用于 reported theft counts，不把相关性解释为因果关系。

## 原理解析范围

### 必须讲清

- neighbourhood-month 面板的含义。
- 时空热力图、热点图和动画分别表达什么。
- 设计矩阵与高等代数中“向量线性组合”的连接。
- B-spline、周期基函数和 RBF 的直觉、公式与作用。
- OLS 最小二乘目标与矩阵形式。
- Ridge 惩罚项、共线性与稳定性的关系。
- 时间切分、基线模型、MAE、RMSE 和 R²。
- 为什么预测值需要从 `log1p` 尺度变回原始计数尺度。

### 不进入正式五分钟演讲

- B-spline 构造的完整证明。
- Ridge 闭式解的逐步矩阵推导。
- 贝叶斯模型、GNN、泊松时空层级模型等额外方法。
- 全部 R 代码逐行解释。
- 完整答辩题答案。

这些内容只在学习附录中按需展开，帮助答辩和后续学习。

## 文档形式

- 使用紧凑参考指南版式。
- 每一页演讲稿包含：时间、对应 PPT 页、逐字稿、指图动作、该页核心句。
- 原理部分采用“直觉 → 数学表达 → 本项目如何实现 → 为什么适合”的固定结构。
- 答辩速查采用简短问题与两层回答：20 秒回答和进一步追问。
- 保留姓名填写位置，不写入个人详细信息。

## 验收标准

- 逐字稿正常语速控制在约五分钟。
- 所有指标与 `output/analysis/model_metrics.csv` 一致。
- 演讲顺序与最终四页 PPT 一致。
- 明确区分 Task 4 的 Basis OLS 与 Ridge 扩展。
- 不声称相关性代表因果关系。
- Word 和 PDF 均无文字溢出、公式乱码、断页异常或大块空白。
