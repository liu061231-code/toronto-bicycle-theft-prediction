# GitHub 研究作品发布设计

## 目标

将 STAT3888 课程作业演化而来的多伦多自行车盗窃预测项目整理为可复现、可审计、适合 GitHub 与研究生申请材料的公开项目。

## 设计决策

1. 在 README 直接使用 GitHub Mermaid，而不额外维护静态 PNG：图片可在 GitHub 上渲染，与代码和文档同步更稳定。
2. 将双语项目介绍放在 `docs/project_introduction.md`，README 保持为快速入门页面。
3. 介绍将 STAT3888 作为项目起点和方法训练来源，但不虚构课程测试成绩、教师或官方合作。
4. 发布前保留所有计算证据和诚实限制：2025 是 retrospective，目标是 published record rows，小时分析是描述性。

## 图示规范

- 项目架构图：体现数据进入、质量保证、面板与特征、时序回测、模型制品和输出。
- 思维流程图：体现课程作业起源、初始模型、问题复盘、修复漏洞、数据刷新、增强特征、分 horizon 选模和可复现发布。

## 发布验收

- README 能让读者在 2分钟内理解项目来源、问题、方法和结果。
- 双语介绍包含方法边界、证据和后续方向。
- 所有 Mermaid 节点指向仓库中实际存在的模块或文件。
- push 后远程分支、GitHub Actions 与仓库文档均可访问。
